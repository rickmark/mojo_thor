Current mechanisms of detection of harm (how to commit a crime, self harm, racism / bigotry) rely on imprecise systems that are commonly jailbroken.  A new mechanism of deep neuron probes can more effectively and efficiently measure this.
## Overview of LLM Layer Concepts

Today we see LLMs as a set of layers of FFNs with no direct mapping to what each layer generally represents.  As the input is fed forward through the layers, it goes from tokens (either common words or partial words) to generally words, to grammatical components, to sentences, to general concepts.  This is why sites such as [neuropedia.com] focus on the middle layers of a LLM.  These go from concepts like "death" to "gothic art" vs to "self harm".  Because of the fact that words like "death" are entirely based on the context wherein they reside, they in and of themselves cannot be used to determine if a prompt or response is about suicide or self harm, murder, or simply the maccabee.  General efforts for mapping the parameters of LLMs is an emerging topic of research, and current mechanisms of harmful prompt / guardrails remain vulnerable to prompt jailbreaks because all such protective layers occur after the general LLM training.  This puts the parameters not at the middle layer where concepts reside, but far at the end of the inference layer stack.  Like a rope with a weight at the end, this "whiplash effect" of LLMs with SFT at the final stage causes the wild moodiness and inconsistency with expected results.  This is because any such SFT like a parrot only understands the tokens and not the driving conceptual structure underlying it.
## Discovering Key Neuronal Elements
Because the process of training a LLM doesn't generally understand the emergent structure of the various parameters in the layers during the AutoGrad stages, the key parameters can only be discovered by reverse engineering the activations after the model is trained.  To be more clear, the parameters are structurally laid out due to the particulars of the tokenization scheme, and multiple epochs of the same input corpus with the same tokenization mapping will produce similar parameters structures, but modifying the tokenization scheme, with the same corpus will drastically change the particulars of the parameters trained.  This is due to the fact that the functor that produces the regression of inputs is mostly-deterministic.  Any such randomness becomes asymptotically small compared to the determinism of the tokenization scheme.
## Determining Neuron Maps vis Adversarial Testing
The best method to determine activation comes from creating a doubling of the memory for parameters.  This permits each flow of activation (the activation of each parameter measured by the amount of each feed forward value) to be passed-to-the-side to a heat map.  After each token is produced, the general side map is lowered to reduce it reaching a maximum value.  This will allow any given input of a concept such as harmful inputs such as "How do I build a bomb" to measure the activation of each neuron.  By feeding this and other negative test cases into the system, one can determine key "harm" activations and differentiate them from non-similar concepts "this playlist is the bomb!".  Once this mapping occurs, one ends up with not just parameters but parameter cohorts that indicate a linked negative case, and those said values can be kept in a side-channel file.  Once this occurs, each forwards pass of the FFN can select such middle layer neurons, and pass them to a side stack, which is itself a ML based detector.  Current silicon in NPU/GPU devices do not have adequate operations to perform this information passing to the side stack in O1 time, and will require redesign of the compute elements to be computationally efficient as activation probes.  We should look at this concept more akin to ARMs Embedded Trace Macrocell and generally use it to pass the flow rate to each neuron measured.

Each of the side channels is a smaller matrix FFN, where each of the N dimensions is the measured neurons, and the M dimension is the associativity of the neurons that create a harm pair.  This then relates to a final dimension H for the particular dimension of harm.  As each token passes, the flow of signal inward will cause the harm dimension to warm when activation occurs, and after each token, all values are cooled in unison.  This makes each of the harm dimensions cool as the input / output continues and changes topic or flows away from the particular harm dimension.  If the dimension flows over a preset threshold, then the circuit breaker will trigger, forcing the LLM to either terminate early, or can trigger a secondary inference step to specifically ask if the input / output meets a particular definition of harm.  This allows highly variable and wide inputs to be checked in an efficient way without having to rely on current mechanisms such as SFT or Second Prompt Checks.
